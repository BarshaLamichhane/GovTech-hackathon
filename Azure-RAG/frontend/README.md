# Azure-RAG Frontend

This React frontend provides a web UI for the Azure-RAG chatbot.

## Setup

1. Install dependencies:

```bash
cd Azure-RAG/frontend
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the browser at the URL shown by Vite.

The frontend sends chat requests to `http://localhost:8000/api/chat` by default.

# Machine Translation for Public Administration

## Summary

The Commercial Register of the Canton of Schwyz and the Integration Unit of the Canton of Zurich implemented machine translation case studies to improve language accessibility and reduce translation costs.

## Ai Use Case

Machine translation of official documents, fact sheets, and administrative correspondence

## Sector

Public Administration

## Data Used

Official documents, administrative texts, and public communication materials

## Risks

- Data security risks from international cloud applications
- Inaccurate translations for legally critical documents
- Unauthorized use of sensitive data
- Lack of specialized terminology for public administration

## Lessons

- Use specialized Swiss providers for machine translation to improve data security and quality
- Train translation models specifically for public administration needs
- Integrate public administration terminology into existing solutions
- Limit machine translation to non-critical documents
- Balance automation with human expertise for accuracy

## Regulations

- Federal Act on Data Protection (FADP)
- Cantonal data protection laws
- Public administration-specific regulations on data security
